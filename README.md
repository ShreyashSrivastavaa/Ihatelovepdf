# ihatelovepdf 🚀

> Fast, secure, and privacy-first PDF utility suite running 100% in your browser.

## 📖 About ihatelovepdf

**ihatelovepdf** is an open-source web application designed to help users merge, split, compress, convert, and edit PDF documents effortlessly. Your files never leave your browser, ensuring maximum data security and privacy.

## ✨ Key Features

- 🔒 **100% Client-Side Privacy**: Your PDFs are processed locally; zero file uploads to external servers.
- ⚡ **Lightning Fast Execution**: Powered by modern WebAssembly and Next.js engine.
- 📄 **Comprehensive PDF Tools**: Merge, split, compress, rotate, and reorder PDF pages seamlessly.
- 🎨 **Modern & Intuitive UI**: Sleek interface with dark mode support and responsive design.
- 📱 **Mobile Friendly**: Works smoothly across mobile, tablet, and desktop devices.
- 🛠️ **Developer Friendly**: Built with TypeScript, Next.js, Tailwind CSS, and PDF-Lib.

## 🛠️ Getting Started

### Prerequisites

Ensure you have Node.js (v18+) and Bun / npm installed on your system.

### Installation

```bash
# Clone the repository
git clone https://github.com/ShreyashSrivastavaa/ihatelovepdf.git

# Navigate to project directory
cd ihatelovepdf

# Install dependencies
bun install   # or npm install
```

### Running Locally

```bash
# Start development server
bun run dev   # or npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.
